# HyperCyano – Robust Hyperspectral Classification of Cyanobacteria

**HyperCyano** studies how experimental design choices affect a hyperspectral (NIR) classifier for cyanobacterial genera: the train/test split level, the preprocessing pipeline, and data augmentation. It asks how much of the accuracy reported by prior work comes from those choices rather than from the model itself.

## ✨ Key Features

- Replicates Fournier et al.'s spectrum-level split and shows how much the metrics drop under a stricter, leakage-free image-level split.
- Isolates the effect of preprocessing by comparing Savitzky-Golay + StandardScaler (the reference pipeline) against Standard Normal Variate (SNV), on both a Random Forest and the reference feed-forward network.
- Compares a Baseline (SNV only) against a Robust model trained with on-the-fly augmentation (additive/multiplicative noise, shift, band masking, mixup and Poisson shot noise) under synthetic sensor corruption, technique by technique, to see where augmentation actually pays off.

## 📦 Installation

```bash
git clone https://github.com/capo-urjc/hypercyano.git
cd hypercyano
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Place the spectra workbook at `data/cyanobacterial_spectra_processed_clean.xlsx`
(or pass `--file` with a different path to any script).

## 🚀 Usage

All scripts live in `src/`, are run from inside that folder, and write their
outputs to `results/<script_name>/`.

```bash
cd src

# 1. Fournier et al. replication: spectrum-level split (reference) vs
#    image-level split (this work), Random Forest + neural network.
python 01_fournier_replication.py

# 2. Preprocessing comparison at the (now stricter) image-level split:
#    Savitzky-Golay + StandardScaler vs SNV, Random Forest + Neural Network.
python 02_preprocessing_comparison.py

# 3. Baseline (SNV) vs Robust (augment -> SNV) under synthetic sensor
#    corruption, technique by technique.
python 03_augmentation_robustness.py
```

Every script accepts `--task {6class,12class,all}` and `--seed`; run
`python <script>.py --help` for the full list of options (e.g. `--model` in
script 1 to run only the Random Forest or only the Neural Network).

### Repository layout

`hsi_data.py`, `hsi_nn.py` and `hsi_augmentations.py` are shared by every
script, so the splitter, metrics and augmentation pool are identical
everywhere and results are directly comparable.

```
hypercyano/
├── data/                          # spectra workbook (not versioned)
├── results/                       # generated by the scripts (not versioned)
├── src/
│   ├── hsi_data.py                # loading, preprocessing, splitting, metrics
│   ├── hsi_nn.py                  # network architecture + augmentation generator
│   ├── hsi_augmentations.py       # spectral augmentation primitives
│   ├── 01_fournier_replication.py
│   ├── 02_preprocessing_comparison.py
│   └── 03_augmentation_robustness.py
└── requirements.txt
```
